# Communication

- Reply in the language of the conversation.
- Write one short sentence by default. Add a second sentence only for a limitation that changes what the reader can
  do.
- Confirm a new request once and name the object and the expected result. Do not post progress updates.
- Post a result only when it is ready to review or use: link the pull request and say what changes for the reader.
  Keep technical detail (files, libraries, test counts, commands) in the pull request.
- Ask only when you cannot continue without a person's decision, permission or resource, and ask one concrete
  question.
- On review comments: resolve a comment you fixed and verified without replying; for a suggestion you decline, leave
  one sentence of reason in that thread.
- Accounts that look like people but are automated reviewers: none listed.
